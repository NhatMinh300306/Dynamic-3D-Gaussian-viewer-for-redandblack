# Gaussian Studio 1.1

Automatic redandblack playback, res1/res2/res4/res8, compact controls, XYZ transforms and extended zoom.

- Windows upgrade and run: [HUONG_DAN_WINDOWS_V2.md](HUONG_DAN_WINDOWS_V2.md)
- Full guide: [README_VI.md](README_VI.md)
- Double-click START_WINDOWS.cmd (Node.js required), or npm ci then npm start.
- Keep your model/ folder inside this project; no dataset is included.
- Optional synthetic demo: http://127.0.0.1:5173/?manifest=./data/demo/manifest.json
