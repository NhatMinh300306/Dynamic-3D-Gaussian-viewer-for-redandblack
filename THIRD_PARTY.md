# Third-party software and references

This project is an independent viewer built on Spark. It is not a World Labs product.

- Spark 2.3.1 — https://github.com/sparkjsdev/spark — MIT license; license included in the static build.
- Three.js 0.180.0 — https://github.com/mrdoob/three.js — MIT license; license included in the static build.
- Spark bundles supporting code including fflate. Preserve the Spark distribution's license comments.
- Dynamic-LapisGS format reference: https://github.com/nus-vv-streams/dynamic-lapis-gs
- CAGS reconstruction reference: https://github.com/yindaheng98/ColorAdaptiveGaussianSplatting

No user training data or 8i assets are included. `public/data/demo` is generated from `scripts/make_demo.py`.
All timing and quality claims for your own scenes must be measured on your own machine.
